<objective>
Build the two host-control DEFINER RPCs (D-04/D-05/D-06): `cancel_night` (E6) does a SOFT unpublish of a creator's own `seeking` night (flip `date_instances.status='cancelled'`, keep the row + interest data, hide from feed eligibility) and notifies already-interested candidates via the new `night_cancelled` notification; `update_night` (E7) lets the creator edit `starts_at`/`duration_min`/venue/ambient and notifies interested candidates via `night_changed` ONLY when a MATERIAL field (time or venue) changes. Both re-check `auth.uid() = creator_id` inside the DEFINER body (NOT via broadened RLS; no `USING(true)`).

Depends on 02-02 for the `night_cancelled`/`night_changed` enum values. These are pure RPC + psql-test surfaces; the host UI that calls them is Plan 02-06 (Wave 3). The notif-map render meta for the two new types lives in Plan 02-05 (render layer).

Purpose: Give hosts the controls to correct or take down a night, and respect the people who swiped in.
Output: Two migrations (cancel_night, update_night), two psql tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated host → cancel_night/update_night | Only the night's creator may cancel/edit; counterparts and outsiders must not |
| RPC → interested candidates | Notification dispatch must originate inside the DEFINER, not from an untrusted caller |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-09 | Elevation of Privilege | cancel_night/update_night DEFINER | mitigate | `p_actor = auth.uid()` re-check + creator-only ownership check (`cre <> p_actor` → 42501); `set search_path=public`; `revoke from public/anon`, grant authenticated only |
| T-02-10 | Tampering | soft-cancel/edit mutation | mitigate | Mutation via DEFINER RPC only; NO `USING(true)` RLS broadening (CLAUDE.md); state-check restricts cancel to `seeking` |
| T-02-11 | Spoofing | candidate notifications | mitigate | `dispatch_notification` performed inside the DEFINER; revoked from public; dedup_key prevents notify-spam |
| T-02-12 | Input Validation | update_night venue/ambient | mitigate | Reuse post_night validators (venue live+active, ambient active, duration CHECK 30..1440); reject invalid with P0001 |
| T-02-SC | Tampering | npm/deno installs | accept | No new packages installed; legitimacy gate N/A |
</threat_model>
