## Spacing Scale

**Project-standard spacing set: {4, 8, 12, 16, 20, 24, 32, 48, 64}** — the full Tailwind 4px-multiple scale.

**Justification:** This project runs on `apps/web/tailwind.config.ts`, which uses Tailwind's default spacing scale (every step a multiple of 4px). `docs/superpowers/DESIGN-SYSTEM.md` is the brand authority and is built on these same stock utilities. The set above extends GSD's canonical base {4, 8, 16, 24, 32, 48, 64} with the two intermediate Tailwind steps **12px (`p-3`/`gap-3`)** and **20px (`px-5`/`gap-5`)**. Both are multiples of 4 and stock Tailwind utilities used across this codebase (e.g. PostNightForm's chip padding and the existing sheet horizontal padding) — they are project-standard, not one-off invented values.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`) | Icon-to-label gap inside a chip |
| sm | 8px (`gap-2`) | Chip-to-chip in a row; sheet chip groups |
| md | 12px (`p-3`/`gap-3`) | Chip internal padding; tight field stacks |
| md+ | 16px (`p-4`/`gap-4`) | Standard field stacks; sheet content rhythm |
| lg | 20px (`px-5`/`gap-5`) | Sheet horizontal padding; between soft/hard groups |
| lg+ | 24px (`px-6`/`gap-6`) | Section gaps; sheet edge padding |
| xl | 32px (`pb-8`) | Sheet bottom padding above the safe area |

Exceptions:
- **Tap targets ≥ 44px** (`min-h-[44px]`) on every chip, sheet control, and the apply/reset buttons (DESIGN-SYSTEM §4, CLAUDE.md). The quick-filter chips and FilterSheet option chips MUST meet this even though their text is small.
- Sheet container is `max-h-[80dvh]`, `max-w-[420px]`, `rounded-t-3xl` — matches the existing FilterSheet stub; do not change.

## Typography

Mirror `tailwind.config.ts` `fontSize` tokens. Headings/CTAs lowercase (DESIGN-SYSTEM §2/§3). Exactly the four roles below for this phase's surfaces. Each role is pinned to a single anchor value so no size serves two roles.

| Role | Size | Weight | Line Height | Token / where |
|------|------|--------|-------------|---------------|
| Body / helper | 15px | regular 400 | 1.5 | `text-[15px]` `font-body` — reach line, sheet descriptions |
| Label (chip / field) | 13px | semibold 600 | 1.5 | `text-[13px]` `font-body font-semibold lowercase` — quick chips, sheet option chips, the fit pill |
| Heading (sheet title) | 28px | regular 400 | 1.2 | `text-3xl` `font-heading lowercase` — "filters" sheet title (matches stub) |
| Display (empty state) | 50px | regular 400 | 1.05 | `text-5xl` `font-heading lowercase` — empty-state hero line (matches existing `EmptyDeck`) |

Weights: regular 400 (Fredoka/Caprasimo default) + semibold 600 (Fredoka, chips/labels/links) — two weights, no more.

## Color

Tier-1 shell tokens (dating chrome). Pink is punctuation, not wallpaper (DESIGN-SYSTEM §1). The feed CARD itself is Tier-2 (per-vibe `--exp-*` via `vibePalette`) and is out of scope to restyle — the fit pill must sit ON the card's existing scrim without fighting the vibe palette.

**60/30/10 distribution: Dominant 60% (`shell.base`) / Secondary 30% (`white/70`–`white/80` + `shell.ink/10`) / Accent 10% (`shell.accent`).**

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `shell.base` `#FAF4EC` | FilterSheet body, feed page canvas, empty-state canvas |
| Secondary (30%) | `white/70`–`white/80` + `shell.ink/10` ring | Unselected chips, sheet field fills, the gear trigger |
| Accent (10%) | `shell.accent` `#E0218A` | SEE reserved list below |
| Ink | `shell.ink` `#3D0F2E` | All text on shell surfaces (at full or `/65`–`/55` opacity for helper text) |
| Success (optional, gated) | `sage` `#5CDBA0` | NOT promoted to a token; do NOT use for the fit pill — keep pink reserved. Fit pill uses accent. |

Accent reserved for: **primary CTA** (sheet "apply filters" button) · **selected/active chip state** (quick chip with a value set; selected option chip in the sheet) · **the "looks for someone like you" fit pill** · **the "loosen" and "post your own night" links in the empty state** · **the gear/filter trigger's active state when filters are set**. Accent is NEVER the chip-row background, NEVER an unselected chip, NEVER the reach-preview line.

Notes:
- **No green/sage on the fit pill** — D-03 wants quiet + flattering, and sage dilutes the pink (DESIGN-SYSTEM §1). The fit pill is `shell.accent` on a translucent white/scrim base, or accent text on `white/85`, kept small.
- **Quick-chip active state**: when a filter has a value, the chip flips to `bg-shell-accent text-white shadow-fun` (same treatment PostNightForm uses for selected pay/gender chips) and may show the value (e.g. "≤ 25km"). Inactive chips are `bg-white/80 text-shell-ink ring-1 ring-shell-ink/10`.
- **Contrast (DESIGN-SYSTEM §9):** white text on `shell.accent` passes; `shell.ink/55` helper text on `shell.base` passes AA for body sizes. Mind the fit pill over the card photo — it sits on the existing bottom scrim, so use `text-white` or a solid accent fill, never accent-on-photo without a backing.

## Copywriting Contract

Voice (CONTEXT §specifics + DESIGN-SYSTEM §3, and the live-QA finding this milestone): **lowercase, dry, Barbiecore, stop-slop**. No em-dashes (use a middot ` · ` or a period), no filler, no adverbs, no "Welcome/Submit/Continue", no motivational lines. Reach-preview and empty-state copy MUST read encouraging, never discouraging.

| Element | Copy |
|---------|------|
| Primary CTA (FilterSheet) | `apply filters` |
| Secondary action (FilterSheet) | `reset filters` (clears all to inclusive defaults; quiet text button, not accent) |
| Quick-chip row (3 chips, D-04) | `distance` · `price` · `vibe` (lowercase; active chip shows its value, e.g. `≤ 25km`, `≤ $80`, `chill`) |
| FilterSheet section labels | hard group header: `dealbreakers` · soft group header: `nice to have`. (Inclusive framing; never "exclude".) |
| FilterSheet hard fields | `who's hosting` (host gender) · `max price` · `how far` |
| FilterSheet soft fields | `vibe` · `who pays` · `when` (time buckets: `this weekend` · `weeknights` · `daytime`) · `their age` (host age range) |
| Fit pill (D-03, NightCard) | `looks for someone like you` (lowercase, small pill; strong matches only via the `fit` flag — not on every card) |
| Reach preview — normal (D-01) | `~{N} people match this in {city}` (quiet line under the radius input; updates live) |
| Reach preview — low count (D-01) | `~{N} match this in {city}. a focused crowd, widen anytime.` (positive framing; NEVER blocks or gates posting) |
| Reach preview — zero / loading | loading: `counting who's around…` · zero: `no one fits this yet in {city}. loosen the targeting and they'll show up.` (never alarming) |
| Empty state heading (D-02) | `nothing fits those filters.` |
| Empty state body (D-02, active recovery) | name the most-restrictive HARD filter + one-tap loosen, e.g. `your distance is set to 10km.` with an accent action `widen to 50km?` — PLUS a second line: `or be the main character. post your own night.` (link to `/nights/new`). No silent auto-relax. |
| Empty state — no filters set (fall back to existing `EmptyDeck`) | keep the shipped line `that's everyone for now.` / `touch grass and come back later.` (this is the genuinely-empty feed, not a filtered-empty feed — do not show "loosen a filter" when no hard filter is set) |
| Error state (filter save / feed reload fails) | sonner toast, lowercase: `that didn't save. try again?` (mirrors the existing `that didn't send. try again?` swipe-error toast) |
| Destructive actions | none in this phase. `reset filters` is reversible (re-set filters anytime); no confirmation dialog needed. |

Copy guardrails for the executor:
- The reach line is **passive + encouraging** — it never renders a warning color, never disables the publish CTA, never says "won't land" or "too narrow."
- The empty state distinguishes **filtered-empty** (D-02 active recovery: name the filter + loosen) from **genuinely-empty** (existing funny `EmptyDeck`). Wire the recovery copy to fire only when a hard filter is active.
- Fit pill is **flattering, not algorithmic** — never "98% match", never a score; just the phrase, only on `fit === true` cards.
- Stop-slop reminder: there is a known em-dash violation at `PostNightForm.tsx:315` (logged in STATE.md). Do NOT introduce new em-dashes in the reach line that lands in the same file.

## Component Contracts

### 1. Quick-filter chip row (D-04) — `SwipeDeck.tsx`

- A horizontal row of **exactly 3 chips** (`distance` · `price` · `vibe`) sits below the feed header (the existing day-scope `h1` + gear stay). The gear/`SlidersHorizontal` trigger remains and also opens the sheet.
- Tapping ANY chip opens the full `FilterSheet` (chips are a shortcut into the sheet, not inline editors).
- Chip mechanics mirror PostNightForm's pay/gender chips: `min-h-[44px] rounded-full px-4 font-body text-[13px] font-semibold lowercase`, deterministic `stickerRotation()` tilt optional but on-brand, `shadow-md`. Inactive = `bg-white/80 text-shell-ink ring-1 ring-shell-ink/10`; active (value set) = `bg-shell-accent text-white shadow-fun` and shows the value.
- Reference `apps/web/components/DatesFilter.tsx` for chip STATE mechanics only — do NOT reuse its warm-token visuals (different brand tier).
- Inclusive default (D-04): a brand-new searcher has every chip inactive (nothing filtered).

### 2. FilterSheet (vaul) — extend `FilterSheet.tsx`

- Keep the existing shell: `Drawer.Root`, `shell-ink/40` overlay, `rounded-t-3xl bg-shell-base max-h-[80dvh] max-w-[420px] shadow-fun`, the grabber, the `font-heading text-3xl lowercase` title "filters".
- Replace the placeholder description + disabled chips with two labeled groups:
  - **`dealbreakers` (hard, HIDE):** `who's hosting` (host gender multi-select chips) · `max price` (slider or stepped chips) · `how far` (distance slider/stepped chips, km). These map to `feed_filters.host_genders` / `max_price` / `max_distance_km`.
  - **`nice to have` (soft, SORT):** `vibe` (multi chips) · `who pays` (multi chips: `i pay` / `they pay` / `split`) · `when` (time buckets: `this weekend` / `weeknights` / `daytime`) · `their age` (host age range, two number inputs styled like PostNightForm's youngest/oldest). Map to `feed_filters.vibes` / `who_pays` / `time_buckets` / `host_age_range`.
- Selected chips use the accent-fill active treatment; multi-select groups use `role="group"` + `role="checkbox"` `aria-checked` exactly like PostNightForm's gender group; who-pays single/multi as appropriate with `role` set.
- Footer: a full-width `apply filters` accent CTA (`h-14 rounded-full bg-shell-accent ... font-heading text-lg lowercase text-white shadow-fun`, copy from the stub's CTA shape) + a quiet `reset filters` text button. On apply: persist to `profiles.feed_filters`, close the sheet, the feed re-queries. On failure: sonner error toast (copy above).
- Inclusive-default framing throughout: the soft `nice to have` group must read as preferences, the hard `dealbreakers` group as the only things that hide. Never label anything "exclude".

### 3. Fit pill (D-03) — `NightCard.tsx`

- Renders ONLY when the card's `fit` flag (from `browse_feed_for_viewer`) is true. Driven by data, not on every card.
- Placement: small pill in the card content stack (on the existing bottom scrim, with the vibe tags / title), or top-left near the `★ curated` seed badge — must not collide with it. Copy: `looks for someone like you`.
- Treatment: small, quiet, flattering. `rounded-full px-3 py-1 font-body text-[13px] font-semibold lowercase`, `shadow-md`, on a `bg-white/85 text-shell-accent` or accent-on-translucent base so it reads on top of any vibe photo. Optional leading `✨` is on-brand (DESIGN-SYSTEM §5b emoji-on-canonical-tag spirit) but keep it subtle.
- Never a score, never a percentage, never on a non-matching card.

### 4. Active-recovery empty state (D-02) — `EmptyDeck` in `SwipeDeck.tsx`

- Two distinct states (do not merge):
  - **Filtered-empty** (a hard filter is active and cleared the feed): heading `nothing fits those filters.`; body names the most-restrictive hard filter and offers a one-tap loosen as an **accent action** (e.g. `widen to 50km?`), PLUS a second accent link `post your own night` → `/nights/new`. No silent auto-relax.
  - **Genuinely-empty** (no hard filter set, deck exhausted): keep the existing funny `that's everyone for now.` / `touch grass and come back later.` + `post your own night` link. Unchanged.
- Layout matches the shipped `EmptyDeck`: centered column, `font-heading text-5xl lowercase` hero, `font-body` body, accent links with `underline decoration-2 underline-offset-4`, `BottomTabShell` at the bottom.
- The "loosen" action updates `feed_filters` (e.g. raises `max_distance_km`) and re-queries — it is a deliberate user tap, never automatic.

### 5. Reach-preview line (D-01) — `PostNightForm.tsx`

- A single quiet line placed under the "who's this for?" fieldset, after the radius input (~line 495). NOT inside its own card; it's helper text.
- Treatment: `font-body text-[13px] lowercase text-shell-ink/65` (matches the existing "open to everyone unless you narrow it." helper one fieldset above). NOT accent, NOT a warning color.
- Updates live as the host adjusts target gender / age / radius (debounced call to the new `reach_preview` RPC).
- Copy states: normal / low / zero / loading per the copywriting table. Low count is framed positively. It MUST NEVER disable or gate the publish CTA (D-01 + spec north star: keep the feed liquid).
- `aria-live="polite"` so the count update is announced without stealing focus (mirrors the `{remaining} left` live region in SwipeDeck).

## Motion & States (DESIGN-SYSTEM §6/§7)

- **Sheet:** vaul's native spring drag (already in the stub). Respect `motion-reduce:` — the stub's CTA already does; carry it to all new controls.
- **Chips:** `active:scale-95`, `hover:scale-105` ONLY under `pointer:fine` (Tailwind `hoverOnlyWhenSupported` is on); add `motion-reduce:transition-none motion-reduce:hover:scale-100`.
- **Fit pill:** static, no hover (it's not actionable). A gentle entrance is acceptable but optional.
- **Every surface declares all six states** (§7): loading (reach line "counting…", sheet apply spinner/disabled), empty (the two empty states above), error (sonner toast), success (filters applied → feed re-queries; optional quiet confirmation), retry (re-open sheet / re-tap apply), cancel (close sheet without applying leaves filters unchanged).
- **Skeletons over spinners**, toasts via `sonner`, focus-visible rings `focus-visible:ring-4 focus-visible:ring-shell-accent/40` on every interactive element (matches existing feed controls).

## Accessibility (DESIGN-SYSTEM §9, CLAUDE.md)

- Tap targets ≥ 44px on all chips and sheet controls.
- Semantic groups: hard/soft chip groups use `role="group"`/`role="radiogroup"` + `aria-checked` (mirror PostNightForm).
- Icon-only controls keep `aria-label` (gear already has `aria-label="filters"`).
- Heading hierarchy preserved: the feed `h1` (day scope) stays the page h1; the sheet uses `Drawer.Title`; empty state hero is a `<p>` not a competing h1 (matches shipped pattern).
- Contrast: white-on-accent and ink-on-base pass AA; verify the fit pill over the darkest vibe photos (it sits on the scrim — keep a solid backing).
- Reach line + fit-pill changes announced via `aria-live="polite"`, not assertive.
