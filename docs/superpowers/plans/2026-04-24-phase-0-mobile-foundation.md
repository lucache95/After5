# Phase 0 — Mobile Foundation + Admin Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the infrastructure foundations that every subsequent phase depends on: shared data/util layer (budget circuit breaker, rate limiting, notification router, CF Images), auth providers (Apple/Google/Phone OTP), admin subdomain (`admin.tryafter5.app`), and deep-link URL patterns (`/d/{slug}`, `/v/{venue}`). None of these ship user-visible features directly — they eliminate retrofits later.

**Architecture:** Hub-and-spoke — Supabase Postgres hub + Vercel web + Inngest workers + external APIs. Additive changes only; no refactors of existing endpoints beyond wrapping them with rate limits and budget gates. All utilities live in `supabase/functions/_shared/` or `packages/api-client` so every subsequent phase can consume them without importing from each other.

**Tech Stack:** Next.js 15 (App Router), Supabase (Postgres + Auth + Storage + Edge Functions Deno), pnpm workspaces, Turbo, Upstash Redis, Cloudflare Images, Apple Developer (Services ID), Google OAuth.

**Spec reference:** `docs/superpowers/specs/2026-04-23-date-engine-v2-architecture-design.md` §5.1, §8.3, §8.8, §8.11 + invariants 15, 16, 18, 19, 20, 21.

**Total estimated time:** ~1.5 weeks of solo-founder work (mix of code + manual account setup + DNS propagation waits).

## Scope waves

This plan is organized as **4 waves**, each independently shippable and committable. Complete a wave, verify, ship to prod if desired, then move to the next. You can stop after any wave and the system is still in a consistent, deployable state.

| Wave | Goal | Estimated time | Blocks |
|---|---|---|---|
| **1** | Database foundations + shared utilities (no user-facing change) | ~2 days | All subsequent waves |
| **2** | Apply Wave 1 utilities to existing endpoints (rate limits + budget gates on generate-plan) | ~1 day | Optional — can defer if Wave 1 done |
| **3** | Auth providers (enable Google, add Apple, add Phone OTP) | ~2 days | Wave 4 admin auth |

Wave 2 is "apply the circuit breaker to existing generate-plan" — skip if you're not worried about runaway cost today. Waves 3 + 4 can be deferred to when they're actively needed (auth for real users, admin subdomain when admin UI gets heavy).

**Files:**

**Why:** `devices` registers push-notification endpoints per user (web push URL now; APNs/FCM later). `notifications` is the delivery log — every dispatch writes one row before hitting the channel.

- [ ] **Step 1: Create the migration file with the two tables and RLS**

```sql
-- supabase/migrations/20260424120000_phase0_devices_notifications.sql

-- ============================================================================
-- Phase 0: Devices + Notifications
-- ============================================================================

-- devices: push-notification endpoint registry, one row per (user_id, platform, token)
create table public.devices (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  platform text not null check (platform in ('ios', 'android', 'web')),
  token text not null,
  registered_at timestamptz not null default now(),
  last_seen_at timestamptz not null default now(),
  is_active boolean not null default true,
  unique (user_id, platform, token)
);
create index idx_devices_user on public.devices(user_id) where is_active;

alter table public.devices enable row level security;

-- Owner can read/write own devices; nobody else.
create policy devices_owner_select on public.devices
  for select using (auth.uid() = user_id);
create policy devices_owner_insert on public.devices
  for insert with check (auth.uid() = user_id);
create policy devices_owner_update on public.devices
  for update using (auth.uid() = user_id);
create policy devices_owner_delete on public.devices
  for delete using (auth.uid() = user_id);

-- notifications: delivery log. service role writes; owner reads.
create table public.notifications (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  type text not null,
  payload jsonb not null default '{}'::jsonb,
  sent_via text not null check (sent_via in ('push_ios', 'push_android', 'web_push', 'email')),
  sent_at timestamptz not null default now(),
  delivered boolean not null default false,
  opened_at timestamptz,
  clicked_at timestamptz
);
create index idx_notifications_user_sent on public.notifications(user_id, sent_at desc);
create index idx_notifications_type on public.notifications(type, sent_at desc);

alter table public.notifications enable row level security;

create policy notifications_owner_select on public.notifications
  for select using (auth.uid() = user_id);
-- no owner INSERT — only service role writes via notification.dispatch

comment on table public.devices is 'Push notification endpoint registry. Web push endpoints land here immediately; APNs/FCM tokens added when mobile apps launch (Phase 7.5).';
```

## Task 1.2 — Migration: monthly_budget + monthly_budget_events

**Files:**
- Create: `supabase/migrations/20260424120100_phase0_monthly_budget.sql`

**Why:** The budget circuit breaker pair. `monthly_budget` holds the spend cap per service per month with atomic `spent_usd` increment. `monthly_budget_events` is the per-call ledger with `workflow_run_id` idempotency so retries don't double-charge. See spec §4.10 and Invariant 15.

- [ ] **Step 1: Create the migration file**

```sql
-- supabase/migrations/20260424120100_phase0_monthly_budget.sql

-- ============================================================================
-- Phase 0: Budget circuit breaker tables
-- ============================================================================

-- monthly_budget: per-service monthly cap. Atomically incremented; row-locked.
create table public.monthly_budget (
  service text not null check (service in (
    'claude', 'replicate', 'elevenlabs',
    'google_places', 'firecrawl', 'resend', 'cloudflare_images'
  )),
  month date not null,                  -- first of month (e.g. '2026-04-01')
  budget_usd numeric(12, 4) not null,
  spent_usd numeric(12, 4) not null default 0,
  alert_at_pct numeric(3, 2) not null default 0.75,
  hard_stop_at_pct numeric(3, 2) not null default 1.00,
  overrun_flag boolean not null default false,  -- set when reconcile would have hard-stopped
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  primary key (service, month)
);

-- monthly_budget_events: per-call cost ledger with idempotency.
create table public.monthly_budget_events (
  id uuid primary key default gen_random_uuid(),
  service text not null,
  month date not null,
  workflow_run_id text not null,
  model text,
  cost_usd numeric(12, 6) not null,
  tokens_input int,
  tokens_output int,
  status text not null default 'reserved' check (status in ('reserved', 'reconciled', 'released')),
  recorded_at timestamptz not null default now(),
  unique (workflow_run_id, service)
);
create index idx_budget_events_service_month on public.monthly_budget_events(service, month, recorded_at desc);

alter table public.monthly_budget enable row level security;
alter table public.monthly_budget_events enable row level security;

-- admin-only: only service role reads/writes. no end-user access.
-- (policies omitted → no default access; service role bypasses RLS by design)

comment on table public.monthly_budget is 'Atomic spend cap per (service, month). Updated via reserve_budget() RPC with row-level lock.';
comment on table public.monthly_budget_events is 'Per-call cost ledger. workflow_run_id idempotency prevents Inngest retries from double-charging.';
```

## Task 1.3 — Migration: budget RPC functions

**Files:**
- Create: `supabase/migrations/20260424120200_phase0_budget_rpcs.sql`

**Why:** Three RPC functions the edge functions call. Must be RPCs (not app-level SQL) because the atomic `UPDATE ... WHERE spent_usd + cost <= budget_usd RETURNING` pattern is load-bearing for Invariant 15. Writing this at app level invites race bugs.

- [ ] **Step 1: Create the migration file**

```sql
-- supabase/migrations/20260424120200_phase0_budget_rpcs.sql

-- ============================================================================
-- Phase 0: Budget RPCs (reserve / reconcile / release)
-- ============================================================================

-- reserve_budget: atomic "check-and-increment" with idempotency-first ordering.
-- Returns ok + is_existing (so withBudget knows whether this call owns the release).
create or replace function public.reserve_budget(
  p_service text,
  p_estimated_cost numeric,
  p_workflow_run_id text,
  p_model text default null
) returns table (
  ok boolean,
  is_existing boolean,        -- true if workflow_run_id was already reserved
  spent_after numeric,
  budget numeric,
  pct_used numeric
) language plpgsql security definer as $$
declare
  v_month date := date_trunc('month', now())::date;
  v_row monthly_budget%rowtype;
  v_new_spent numeric;
  v_inserted_id uuid;
begin
  -- Look up budget row; lock it for the duration of this transaction.
  select * into v_row
    from monthly_budget
    where service = p_service and month = v_month
    for update;

  if not found then
    raise exception 'No budget configured for service=% month=%', p_service, v_month;
  end if;

  -- IDEMPOTENCY FIRST: try to insert the ledger row. If (workflow_run_id, service) already
  -- exists, the insert returns NULL and we return the existing budget snapshot WITHOUT
  -- incrementing spent_usd. This prevents double-charge on Inngest retry.
  insert into monthly_budget_events (service, month, workflow_run_id, model, cost_usd, status)
    values (p_service, v_month, p_workflow_run_id, p_model, p_estimated_cost, 'reserved')
    on conflict (workflow_run_id, service) do nothing
    returning id into v_inserted_id;

  if v_inserted_id is null then
    -- Already reserved; caller is a retry. Return current budget state; caller must NOT release.
    return query select
      true,                     -- ok (the original reservation succeeded)
      true,                     -- is_existing
      v_row.spent_usd,
      v_row.budget_usd,
      (v_row.spent_usd / v_row.budget_usd);
    return;
  end if;

  -- New reservation. Now check hard-stop.
  v_new_spent := v_row.spent_usd + p_estimated_cost;
  if v_new_spent > v_row.budget_usd * v_row.hard_stop_at_pct then
    -- Roll back the ledger insert we just made.
    delete from monthly_budget_events where id = v_inserted_id;
    return query select
      false,                    -- ok (hard-stopped)
      false,                    -- is_existing
      v_row.spent_usd,
      v_row.budget_usd,
      (v_row.spent_usd / v_row.budget_usd);
    return;
  end if;

  -- Increment atomically.
  update monthly_budget
    set spent_usd = v_new_spent, updated_at = now()
    where service = p_service and month = v_month;

  return query select
    true,
    false,                      -- is_existing
    v_new_spent,
    v_row.budget_usd,
    (v_new_spent / v_row.budget_usd);
end;
$$;

-- reconcile_budget: post-call, write actual cost. Re-checks hard-stop on overruns
-- and sets overrun_flag so the admin dashboard can surface chronic under-estimation.
create or replace function public.reconcile_budget(
  p_workflow_run_id text,
  p_service text,
  p_actual_cost numeric,
  p_tokens_input int default null,
  p_tokens_output int default null
) returns void language plpgsql security definer as $$
declare
  v_event monthly_budget_events%rowtype;
  v_delta numeric;
  v_month date;
  v_budget monthly_budget%rowtype;
  v_new_spent numeric;
begin
  select * into v_event
    from monthly_budget_events
    where workflow_run_id = p_workflow_run_id and service = p_service
    for update;

  if not found then
    raise exception 'No reservation found for workflow_run_id=% service=%', p_workflow_run_id, p_service;
  end if;

  if v_event.status != 'reserved' then
    -- Already reconciled or released; idempotent no-op.
    return;
  end if;

  v_delta := p_actual_cost - v_event.cost_usd;
  v_month := v_event.month;

  -- Update the event row to actual.
  update monthly_budget_events
    set cost_usd = p_actual_cost,
        tokens_input = coalesce(p_tokens_input, tokens_input),
        tokens_output = coalesce(p_tokens_output, tokens_output),
        status = 'reconciled',
        recorded_at = now()
    where id = v_event.id;

  -- Apply delta to budget under lock.
  select * into v_budget from monthly_budget
    where service = p_service and month = v_month for update;
  v_new_spent := v_budget.spent_usd + v_delta;

  -- Overrun guard: if actual pushes us past the hard-stop that reserve_budget would have
  -- rejected, set overrun_flag and log loudly. Spec §8.3: "if actual > estimated, the
  -- reconciliation re-checks against budget and raises a flag if it would have hard-stopped."
  -- We still apply the delta (can't unmake the call) but flag the service for the dashboard.
  if v_new_spent > v_budget.budget_usd * v_budget.hard_stop_at_pct then
    raise warning 'Budget overrun on service=% month=%: spent would be % vs cap %',
      p_service, v_month, v_new_spent, v_budget.budget_usd * v_budget.hard_stop_at_pct;
    update monthly_budget
      set spent_usd = v_new_spent, overrun_flag = true, updated_at = now()
      where service = p_service and month = v_month;
  else
    update monthly_budget
      set spent_usd = v_new_spent, updated_at = now()
      where service = p_service and month = v_month;
  end if;
end;
$$;

-- release_budget: external call failed, roll back the reservation.
create or replace function public.release_budget(
  p_workflow_run_id text,
  p_service text
) returns void language plpgsql security definer as $$
declare
  v_event monthly_budget_events%rowtype;
begin
  select * into v_event
    from monthly_budget_events
    where workflow_run_id = p_workflow_run_id and service = p_service
    for update;

  if not found or v_event.status != 'reserved' then
    return;  -- nothing to release or already finalized
  end if;

  update monthly_budget
    set spent_usd = spent_usd - v_event.cost_usd, updated_at = now()
    where service = p_service and month = v_event.month;

  update monthly_budget_events
    set status = 'released', recorded_at = now()
    where id = v_event.id;
end;
$$;

-- Grant execute to service role only (edge functions run as service role).
revoke execute on function public.reserve_budget(text, numeric, text, text) from public, anon, authenticated;
revoke execute on function public.reconcile_budget(text, text, numeric, int, int) from public, anon, authenticated;
revoke execute on function public.release_budget(text, text) from public, anon, authenticated;
grant execute on function public.reserve_budget(text, numeric, text, text) to service_role;
grant execute on function public.reconcile_budget(text, text, numeric, int, int) to service_role;
grant execute on function public.release_budget(text, text) to service_role;
```

## Task 1.5 — Shared utility: rate-limit wrapper

**Files:**
- Create: `supabase/functions/_shared/rate-limit.ts`

**Why:** Invariant 18 — per-user rate limits on expensive routes. Upstash Redis + a token-bucket algorithm. Single wrapper used by every edge function that calls a paid external API or write-amplifies `events`.

- [ ] **Step 1: Create the rate-limit module**

```typescript
// supabase/functions/_shared/rate-limit.ts
// Per-route per-bucket token-bucket rate limiter backed by Upstash Redis.
// Usage:
//   const check = await rateLimit({ bucket: `gen-plan:${userId}`, limit: 20, windowSec: 3600 });
//   if (!check.ok) return new Response(..., { status: 429, headers: { 'Retry-After': check.retryAfter } });

export interface RateLimitInput {
  bucket: string;          // unique per user+route, e.g. "gen-plan:user-uuid"
  limit: number;           // max requests in window
  windowSec: number;       // sliding window in seconds
}

export interface RateLimitResult {
  ok: boolean;
  remaining: number;       // tokens left in current window
  resetAt: number;         // unix seconds when window resets
  retryAfter: string;      // seconds to wait (only set when !ok)
}

const UPSTASH_URL = Deno.env.get('UPSTASH_REDIS_REST_URL');
const UPSTASH_TOKEN = Deno.env.get('UPSTASH_REDIS_REST_TOKEN');

if (!UPSTASH_URL || !UPSTASH_TOKEN) {
  console.warn('[rate-limit] UPSTASH_REDIS_REST_URL / UPSTASH_REDIS_REST_TOKEN not set — rate limiting disabled');
}

/**
 * Check rate limit using INCR + EXPIRE in Redis.
 * Fail open: if Upstash is unreachable, allow the request (we don't want rate-limit infra outage
 * to take the product down). Logs a warning so the outage is visible in observability.
 */
export async function rateLimit(input: RateLimitInput): Promise<RateLimitResult> {
  if (!UPSTASH_URL || !UPSTASH_TOKEN) {
    return { ok: true, remaining: input.limit, resetAt: 0, retryAfter: '0' };
  }

  const key = `rl:${input.bucket}`;
  const pipeline = [
    ['INCR', key],
    ['EXPIRE', key, String(input.windowSec), 'NX'],
    ['TTL', key],
  ];

  try {
    const res = await fetch(`${UPSTASH_URL}/pipeline`, {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${UPSTASH_TOKEN}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify(pipeline),
    });

    if (!res.ok) {
      console.warn(`[rate-limit] Upstash returned ${res.status}; failing open`);
      return { ok: true, remaining: input.limit, resetAt: 0, retryAfter: '0' };
    }

    const data = await res.json() as Array<{ result: number }>;
    const [count, , ttl] = data.map((d) => d.result);
    const resetAt = Math.floor(Date.now() / 1000) + (ttl > 0 ? ttl : input.windowSec);
    const remaining = Math.max(0, input.limit - count);

    if (count > input.limit) {
      return {
        ok: false,
        remaining: 0,
        resetAt,
        retryAfter: String(ttl > 0 ? ttl : input.windowSec),
      };
    }

    return { ok: true, remaining, resetAt, retryAfter: '0' };
  } catch (err) {
    console.warn('[rate-limit] error, failing open:', err);
    return { ok: true, remaining: input.limit, resetAt: 0, retryAfter: '0' };
  }
}

/**
 * Helper: compute the 429 response for a failed rate-limit check.
 */
export function rateLimitResponse(result: RateLimitResult, corsHeaders: Record<string, string> = {}): Response {
  return new Response(
    JSON.stringify({
      error: 'rate_limit_exceeded',
      message: 'Too many requests. Try again in a moment.',
      retry_after_seconds: Number(result.retryAfter),
    }),
    {
      status: 429,
      headers: {
        'Content-Type': 'application/json',
        'Retry-After': result.retryAfter,
        'X-RateLimit-Remaining': '0',
        'X-RateLimit-Reset': String(result.resetAt),
        ...corsHeaders,
      },
    },
  );
}
```

```typescript
// supabase/functions/_shared/service-pricing.ts
// Single source of truth for external-service pricing.
// Update when providers change prices. Keep in sync with monthly_budget.service enum.

// Service names must match the CHECK constraint in monthly_budget.service.
// Note: 'claude' covers ALL Claude API usage (Sonnet + Haiku + Vision) — they share
// a single budget line. Differentiate model via the `model` field on the event row.
export type ServiceName =
  | 'claude'
  | 'replicate'
  | 'elevenlabs'
  | 'google_places'
  | 'firecrawl'
  | 'resend'
  | 'cloudflare_images';

export interface CostInputs {
  model?: string;
  tokensInput?: number;
  tokensOutput?: number;
  imagesGenerated?: number;
  callsMade?: number;
  chars?: number;
}

/**
 * Estimate the cost of an external call BEFORE making it.
 * Returns cost in USD. Conservative — rounds up to avoid under-reservation.
 */
export function estimateCost(service: ServiceName, inputs: CostInputs): number {
  switch (service) {
    case 'claude': {
      // Model selected via inputs.model. Default to Sonnet pricing for unknown.
      const isHaiku = inputs.model?.includes('haiku');
      const inRate = isHaiku ? 0.8 : 3;     // $/M input tokens
      const outRate = isHaiku ? 4 : 15;     // $/M output tokens
      const inCost = ((inputs.tokensInput ?? 0) / 1_000_000) * inRate;
      const outCost = ((inputs.tokensOutput ?? 0) / 1_000_000) * outRate;
      return round(inCost + outCost);
    }
    case 'replicate': {
      // FLUX schnell: ~$0.003/img, FLUX 1.1 pro: ~$0.04/img
      const perImage = inputs.model?.includes('pro') ? 0.04 : 0.003;
      return round((inputs.imagesGenerated ?? 1) * perImage);
    }
    case 'elevenlabs': {
      // ~$0.30 / 1000 chars
      return round(((inputs.chars ?? 0) / 1000) * 0.3);
    }
    case 'google_places': {
      // Worst case enterprise+atmosphere tier: $0.04/call at <1k
      // Typical: ~$0.017/call (details essentials + photos)
      return round((inputs.callsMade ?? 1) * 0.017);
    }
    case 'firecrawl': {
      // ~$0.0008/page at scale
      return round((inputs.callsMade ?? 1) * 0.0008);
    }
    case 'resend': {
      // Free tier covers Phase 0. Nominal 0.
      return 0;
    }
    case 'cloudflare_images': {
      // No per-delivery cost on the paid plan; $0 estimate ok
      return 0;
    }
  }
}

function round(n: number): number {
  return Math.ceil(n * 1_000_000) / 1_000_000;
}
```

- [ ] **Step 2: Create the budget wrapper**

```typescript
// supabase/functions/_shared/budget.ts
// Thin TypeScript wrapper around reserve_budget / reconcile_budget / release_budget RPCs.
// Enforces Invariant 15: every external-AI call passes an atomic budget gate.

import { createClient } from 'https://esm.sh/@supabase/supabase-js@2.45.0';
import type { ServiceName } from './service-pricing.ts';

const supabaseUrl = Deno.env.get('SUPABASE_URL')!;
const supabaseServiceRoleKey = Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!;

const admin = createClient(supabaseUrl, supabaseServiceRoleKey, {
  auth: { persistSession: false },
});

export interface ReserveResult {
  ok: boolean;
  isExisting: boolean;   // true if this workflow_run_id was already reserved — caller must NOT release
  spentAfter: number;
  budget: number;
  pctUsed: number;
}

export async function reserveBudget(
  service: ServiceName,
  estimatedCost: number,
  workflowRunId: string,
  model?: string,
): Promise<ReserveResult> {
  const { data, error } = await admin.rpc('reserve_budget', {
    p_service: service,
    p_estimated_cost: estimatedCost,
    p_workflow_run_id: workflowRunId,
    p_model: model ?? null,
  });

  if (error) throw new Error(`reserveBudget failed: ${error.message}`);
  const row = (data as any[])[0];
  const result: ReserveResult = {
    ok: row.ok,
    isExisting: row.is_existing,
    spentAfter: Number(row.spent_after),
    budget: Number(row.budget),
    pctUsed: Number(row.pct_used),
  };

  if (result.pctUsed >= 0.75 && result.ok) {
    console.warn(`[budget] ${service} at ${(result.pctUsed * 100).toFixed(1)}% of monthly cap`);
  }
  return result;
}

export async function reconcileBudget(
  workflowRunId: string,
  service: ServiceName,
  actualCost: number,
  tokensInput?: number,
  tokensOutput?: number,
): Promise<void> {
  const { error } = await admin.rpc('reconcile_budget', {
    p_workflow_run_id: workflowRunId,
    p_service: service,
    p_actual_cost: actualCost,
    p_tokens_input: tokensInput ?? null,
    p_tokens_output: tokensOutput ?? null,
  });
  if (error) throw new Error(`reconcileBudget failed: ${error.message}`);
}

export async function releaseBudget(workflowRunId: string, service: ServiceName): Promise<void> {
  const { error } = await admin.rpc('release_budget', {
    p_workflow_run_id: workflowRunId,
    p_service: service,
  });
  if (error) throw new Error(`releaseBudget failed: ${error.message}`);
}

/**
 * Convenience wrapper: reserve → run → reconcile/release.
 * Use when you know the exact call and its cost bounds.
 */
export async function withBudget<T>(
  service: ServiceName,
  estimatedCost: number,
  workflowRunId: string,
  run: () => Promise<{ result: T; actualCost: number; tokensInput?: number; tokensOutput?: number }>,
  model?: string,
): Promise<T> {
  const reserved = await reserveBudget(service, estimatedCost, workflowRunId, model);
  if (!reserved.ok) {
    throw new Error(`budget_exceeded:${service}:${reserved.pctUsed}`);
  }
  // If this call reactivated an existing reservation (retry), we do NOT own the release.
  // Only the original caller can release; a retry releasing would corrupt the budget.
  const ownsRelease = !reserved.isExisting;

  try {
    const { result, actualCost, tokensInput, tokensOutput } = await run();
    await reconcileBudget(workflowRunId, service, actualCost, tokensInput, tokensOutput);
    return result;
  } catch (err) {
    if (ownsRelease) {
      await releaseBudget(workflowRunId, service).catch(() => {}); // best-effort
    }
    throw err;
  }
}
```

```typescript
// supabase/functions/_shared/notification-router.ts
// Single entrypoint for all user-facing notifications.
// Routes to APNs / FCM / Web Push / Email based on devices table + preferences.
// Phase 0 implements: Web Push + Email. APNs/FCM stubs are log-only.

import { createClient } from 'https://esm.sh/@supabase/supabase-js@2.45.0';

const supabaseUrl = Deno.env.get('SUPABASE_URL')!;
const supabaseServiceRoleKey = Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!;
const resendApiKey = Deno.env.get('RESEND_API_KEY');

const admin = createClient(supabaseUrl, supabaseServiceRoleKey, {
  auth: { persistSession: false },
});

export type NotificationType =
  | 'match' | 'swipe' | 'reminder' | 'rating_prompt' | 'moderation' | 'outreach_response' | 'welcome';

export interface DispatchInput {
  userId: string;
  type: NotificationType;
  payload: Record<string, unknown>;
  /** Fallback email recipient if user has no push devices. */
  emailFallback?: { to: string; subject: string; html: string };
}

export async function dispatch(input: DispatchInput): Promise<void> {
  const { userId, type, payload, emailFallback } = input;

  // Look up active devices for this user.
  const { data: devices, error } = await admin
    .from('devices')
    .select('*')
    .eq('user_id', userId)
    .eq('is_active', true);

  if (error) {
    console.error(`[notify] failed to load devices for ${userId}:`, error);
  }

  const deliveryPromises: Promise<{ channel: string; delivered: boolean }>[] = [];

  for (const device of devices ?? []) {
    if (device.platform === 'web') {
      deliveryPromises.push(sendWebPush(device.token, type, payload).then((ok) => ({ channel: 'web_push', delivered: ok })));
    } else if (device.platform === 'ios') {
      // Phase 7.5 — APNs
      console.log(`[notify] (stub) would send APNs to ${device.token.slice(0, 16)}...`);
      deliveryPromises.push(Promise.resolve({ channel: 'push_ios', delivered: false }));
    } else if (device.platform === 'android') {
      // Phase 7.5 — FCM
      console.log(`[notify] (stub) would send FCM to ${device.token.slice(0, 16)}...`);
      deliveryPromises.push(Promise.resolve({ channel: 'push_android', delivered: false }));
    }
  }

  // If no active push devices AND emailFallback provided, send email.
  if ((devices?.length ?? 0) === 0 && emailFallback) {
    deliveryPromises.push(sendEmail(emailFallback).then((ok) => ({ channel: 'email', delivered: ok })));
  }

  const results = await Promise.allSettled(deliveryPromises);

  // Log every delivery attempt to notifications table (fire-and-forget).
  const logRows = results.flatMap((r) => {
    if (r.status !== 'fulfilled') return [];
    return [{
      user_id: userId,
      type,
      payload,
      sent_via: r.value.channel,
      delivered: r.value.delivered,
    }];
  });
  if (logRows.length > 0) {
    admin.from('notifications').insert(logRows).then(({ error }) => {
      if (error) console.error('[notify] log insert failed:', error);
    });
  }
}

async function sendWebPush(
  subscription: string,  // JSON-serialized PushSubscription
  type: NotificationType,
  payload: Record<string, unknown>,
): Promise<boolean> {
  try {
    const sub = JSON.parse(subscription);
    // NOTE: Web Push requires VAPID keys + a signed JWT. For Phase 0, we use the web-push npm lib
    // via a small edge function. The real encryption is done there; this is a placeholder that
    // posts to our own internal dispatch endpoint.
    const res = await fetch(`${supabaseUrl}/functions/v1/send-web-push`, {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${supabaseServiceRoleKey}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({ subscription: sub, type, payload }),
    });
    return res.ok;
  } catch (err) {
    console.error('[notify] web push error:', err);
    return false;
  }
}

async function sendEmail(input: { to: string; subject: string; html: string }): Promise<boolean> {
  if (!resendApiKey) {
    console.warn('[notify] RESEND_API_KEY not set; email skipped');
    return false;
  }
  try {
    const res = await fetch('https://api.resend.com/emails', {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${resendApiKey}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        from: 'After5 <hello@tryafter5.app>',
        to: input.to,
        subject: input.subject,
        html: input.html,
      }),
    });
    return res.ok;
  } catch (err) {
    console.error('[notify] email error:', err);
    return false;
  }
}
```

```typescript
// apps/web/lib/cloudflare-images.ts
// Cloudflare Images URL construction.
// Requires NEXT_PUBLIC_CF_IMAGES_ACCOUNT_HASH in env.

const CF_HASH = process.env.NEXT_PUBLIC_CF_IMAGES_ACCOUNT_HASH ?? '';

export type CfImageSize = 'thumb' | 'card' | 'full' | 'cover';

const SIZE_VARIANTS: Record<CfImageSize, string> = {
  thumb: 'thumbnail', // 300px
  card: 'public',     // 800px — default CF variant name
  full: 'large',      // 1600px
  cover: 'hero',      // 2400×1350 for hero sections
};

/**
 * Construct a CF Images URL for a given image ID and size variant.
 * Returns null if CF_HASH isn't configured so callers can cleanly fall back
 * (returning '' would look like a valid string and could silently break <img>).
 */
export function cfImageUrl(imageId: string, size: CfImageSize = 'card'): string | null {
  if (!CF_HASH || !imageId) return null;
  const variant = SIZE_VARIANTS[size];
  return `https://imagedelivery.net/${CF_HASH}/${imageId}/${variant}`;
}

/**
 * For existing Supabase Storage / Google Places URLs that haven't migrated to CF yet,
 * return them as-is. Phase 1 image pipeline will replace these.
 */
export function resolveImageUrl(
  primaryCfId: string | null,
  fallbackUrl: string | null,
  size: CfImageSize = 'card',
): string | null {
  if (primaryCfId) {
    const cfUrl = cfImageUrl(primaryCfId, size);
    if (cfUrl) return cfUrl;
  }
  return fallbackUrl;
}
```

```tsx
// apps/web/app/auth/phone/page.tsx
'use client';

import { useState } from 'react';
import { useRouter } from 'next/navigation';
import { createClient } from '@/lib/supabase/client';

export default function PhoneAuthPage() {
  const router = useRouter();
  const supabase = createClient();
  const [phone, setPhone] = useState('');
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);

  async function handleSubmit(e: React.FormEvent) {
    e.preventDefault();
    setLoading(true);
    setError(null);

    // Phone must be E.164 format: +1XXXXXXXXXX
    const normalized = phone.startsWith('+') ? phone : `+1${phone.replace(/\D/g, '')}`;

    // App-layer rate limit mirror (Invariant 18 — spec §8.11 says mirror Supabase Auth's
    // built-in SMS rate limit at app layer for observability). 5/hr per phone.
    // This is a client-side best-effort check; Supabase Auth enforces server-side too.
    const rlKey = `phone-otp:${normalized}`;
    const rlState = JSON.parse(localStorage.getItem(rlKey) ?? '{"count":0,"resetAt":0}');
    const now = Date.now();
    if (now > rlState.resetAt) {
      rlState.count = 0;
      rlState.resetAt = now + 3600_000;
    }
    if (rlState.count >= 5) {
      setError('Too many code requests for this number. Try again in an hour.');
      setLoading(false);
      return;
    }
    rlState.count += 1;
    localStorage.setItem(rlKey, JSON.stringify(rlState));

    const { error } = await supabase.auth.signInWithOtp({
      phone: normalized,
    });

    if (error) {
      setError(error.message);
      setLoading(false);
      return;
    }

    router.push(`/auth/phone/verify?phone=${encodeURIComponent(normalized)}`);
  }

  return (
    <div className="mx-auto max-w-md p-6">
      <h1 className="text-2xl font-semibold mb-4">Sign in with your phone</h1>
      <form onSubmit={handleSubmit} className="space-y-4">
        <input
          type="tel"
          value={phone}
          onChange={(e) => setPhone(e.target.value)}
          placeholder="(250) 555-0123"
          required
          className="w-full rounded-lg border border-neutral-300 px-4 py-2.5"
        />
        {error && <p className="text-red-600 text-sm">{error}</p>}
        <button
          type="submit"
          disabled={loading || !phone}
          className="w-full rounded-lg bg-neutral-900 py-2.5 font-medium text-white disabled:opacity-50"
        >
          {loading ? 'Sending code...' : 'Send code'}
        </button>
      </form>
    </div>
  );
}
```

- [ ] **Step 1: Create the server-side Supabase client for admin**

```typescript
// apps/admin/lib/supabase/server.ts
import { createServerClient, type CookieOptions } from '@supabase/ssr';
import { cookies } from 'next/headers';
import type { Database } from '@after5/types/database';

/**
 * Reads auth cookies from the root domain (.tryafter5.app) so both the user app
 * and the admin app share a single session.
 */
export function createClient() {
  const cookieStore = cookies();
  return createServerClient<Database>(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY!,
    {
      cookies: {
        get(name: string) {
          return cookieStore.get(name)?.value;
        },
        set(name: string, value: string, options: CookieOptions) {
          cookieStore.set({ name, value, ...options, domain: '.tryafter5.app' });
        },
        remove(name: string, options: CookieOptions) {
          cookieStore.set({ name, value: '', ...options, domain: '.tryafter5.app', maxAge: 0 });
        },
      },
    },
  );
}
```

- [ ] **Step 2: Create the middleware**

```typescript
// apps/admin/middleware.ts
import { NextResponse, type NextRequest } from 'next/server';
import { createServerClient } from '@supabase/ssr';

export async function middleware(request: NextRequest) {
  const response = NextResponse.next();

  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY!,
    {
      cookies: {
        get(name) { return request.cookies.get(name)?.value; },
        set(name, value, options) {
          response.cookies.set({ name, value, ...options, domain: '.tryafter5.app' });
        },
        remove(name, options) {
          response.cookies.set({ name, value: '', ...options, domain: '.tryafter5.app', maxAge: 0 });
        },
      },
    },
  );

  const { data: { user } } = await supabase.auth.getUser();

  // Not logged in → bounce to main app's login page.
  if (!user) {
    return NextResponse.redirect(new URL('https://tryafter5.app/login?next=https://admin.tryafter5.app'));
  }

  // Check admin claim. Two sources of truth:
  //   1. app_metadata.is_admin (production)
  //   2. ADMIN_EMAILS env var (legacy, fallback)
  const isAdmin = Boolean(user.app_metadata?.is_admin) ||
    (process.env.ADMIN_EMAILS ?? '').split(',').map(s => s.trim().toLowerCase()).includes(user.email?.toLowerCase() ?? '');

  if (!isAdmin) {
    // Not an admin — kick back to main app.
    return NextResponse.redirect(new URL('https://tryafter5.app/'));
  }

  return response;
}

export const config = {
  matcher: [
    // protect everything except static + favicon
    '/((?!_next/static|_next/image|favicon.ico).*)',
  ],
};
```
